# Flipkart E-Commerce Data Analysis

## Project Overview

This project performs exploratory data analysis (EDA) on Flipkart
e-commerce product data using Python.

The objective is to identify patterns in product pricing, discounts,
ratings, categories and brands and generate data-driven business insights.

## Business Problem

The analysis focuses on understanding product performance, pricing
patterns and customer-related metrics to support data-driven
business decisions.

## Dataset

The dataset contains Flipkart product information including:

- Product titles
- Product categories
- Product descriptions
- Prices
- MRP
- Discounts
- Ratings
- Reviews
- Brand information

The dataset was obtained from Kaggle.

## Objectives

- Clean and prepare the dataset
- Analyze product pricing
- Analyze discounts
- Study product categories
- Analyze customer ratings
- Examine brand distribution
- Identify relationships between pricing and ratings
- Generate business insights

## Technologies

- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Jupyter Notebook

## Project Workflow

Data Collection
→ Data Cleaning
→ Data Transformation
→ Exploratory Data Analysis
→ Correlation Analysis
→ Business Insights
→ Recommendations
